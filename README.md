# Colombus FX Risk Alert Dashboard

A full-stack foreign exchange monitoring dashboard that tracks live exchange rates, computes risk alerts, and delivers AI-generated market commentary for four currency pairs: **EUR/USD**, **GBP/USD**, **USD/TND**, and **EUR/TND**.

---

## Features

- **Live rate charts** — historical exchange rates plotted over a configurable date range
- **KPI cards** — daily change %, weekly/monthly performance, and 30-day high/low
- **Volatility gauge** — annualized volatility indicator with a visual gauge
- **Risk alerts** — LOW / MEDIUM / HIGH classification based on daily % movement and spike detection
- **Cross-pair comparison table** — side-by-side summary for all tracked pairs
- **AI market commentary** — narrative insights generated by Llama 3.3 (via Groq), cached per pair per day
- **Dark / light theme** toggle

## Getting Started

### Prerequisites

- Python 3.11+
- Node.js 18+ *(for the frontend)*
- A [Groq API key](https://console.groq.com) *(for AI commentary)*

### Backend

```bash
cd Backend

# Install dependencies
pip install -r requirements.txt

# Create .env file
cp .env.example .env       # then fill in your GROQ_API_KEY
# or manually create Backend/.env:
#   DATABASE_URL=sqlite:///./fx_dashboard.db
#   GROQ_API_KEY=your_key_here

# Seed the database
python scripts/seed_currencies.py
python scripts/seed_tnd_rates.py   # loads historical TND data from CSV

# Start the API server
python -m uvicorn app.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`. Interactive docs: `http://localhost:8000/docs`.

### Frontend

```bash
cd frontend

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will open at `http://localhost:5174`. Vite proxies `/api` requests to the backend.

## API Reference

All endpoints are prefixed with `/api/v1`.

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/rates/{base}/{quote}` | Historical rates for a date range |
| `GET` | `/rates/{base}/{quote}/daily-change` | Daily change amount and % |
| `GET` | `/rates/{base}/{quote}/performance` | Weekly or monthly performance |
| `GET` | `/rates/{base}/{quote}/high-low` | Period high and low |
| `GET` | `/rates/{base}/{quote}/volatility` | Annualized volatility |
| `GET` | `/alerts/{base}/{quote}` | Risk alert for a given date |
| `GET` | `/alerts/{base}/{quote}/history` | Alert history over a date range |
| `GET` | `/analysis/summary` | Cross-pair snapshot (most volatile, biggest mover, etc.) |
| `POST` | `/ai/commentary` | AI-generated market commentary |

Supported pairs: `EUR/USD`, `GBP/USD`, `USD/TND`, `EUR/TND`.
